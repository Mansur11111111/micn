# Micn

Финансовый помощник для людей, которым трудно с деньгами. Работает в браузере, данные хранятся только на вашем устройстве.

## Что умеет

- Учёт трат и способов оплаты, панель с диаграммой, цели с полосой прогресса
- Калькуляторы: накопления, долги (лавина и снежный ком), бюджет, бизнес, стресс-тест «что если я потеряю доход»
- План «Деньги кончились до зарплаты»
- Письма и заявления банку, арендодателю и другим организациям
- Выгрузка трат в CSV
- AI-помощник: отчёты, инструменты и чат (нужен сервер или публикация в Claude, см. ниже)

## Структура проекта

```text
index.html                 Разметка страницы: шапка, вкладки и разделы
assets/
  css/style.css            Все стили (цвета и тёмная тема в начале файла)
  js/
    config.js              Настройки: адрес AI-сервера, вход, реквизиты оплаты
    core.js                Данные пользователя и общие помощники
    tracker.js             Траты, панель, выгрузка CSV
    goals.js               Цели
    ai-core.js             Доступ к AI, язык, лимиты, сообщения об ошибках
    ai-tools.js            AI-отчёт, инструменты и чат
    calculators.js         Все калькуляторы
    letters.js             Письма и заявления
    subscription.js        Подписка и донат
    account.js             Вход и тариф
    tabs.js                Переключение вкладок
    main.js                Запуск
.github/workflows/pages.yml  Автопубликация на GitHub Pages
```

Порядок подключения скриптов в `index.html` важен: файлы работают как одна программа, поэтому `config.js` идёт первым, а `main.js` последним.

## Как опубликовать на GitHub Pages

1. Загрузите все файлы в корень репозитория (кнопка Add file → Upload files).
2. Откройте Settings → Pages. Выберите Source: GitHub Actions (если используете `pages.yml`) или Deploy from a branch → main / root.
3. Подождите 1–3 минуты и откройте адрес сайта. Внизу страницы написана версия.

Проще всего загрузить один файл `index.html` из сборки «в одном файле»: в нём уже лежат стили и скрипты.

## Настройка

Все настройки лежат в `assets/js/config.js`:

- `WORKER_URL`: адрес сервера с AI. Если пусто, блоки AI скрыты, остальное работает.
- `SB`: данные Supabase для входа по email (публичный ключ можно хранить на сайте).
- `PAY`: реквизиты для ручной оплаты. Ссылка на донат лежит в `index.html`.

Секретные ключи (Anthropic, Telegram, Stripe, секретный ключ Supabase) в репозиторий добавлять нельзя. Они хранятся только в настройках сервера.

## Куда смотреть, если нужно изменить

- Текст или порядок блоков: `index.html`
- Цвета и вид: `assets/css/style.css`
- Расчёты калькуляторов: `assets/js/calculators.js`
- Тексты писем: `assets/js/letters.js`
- Правила и тон AI: функция `base()` в `assets/js/ai-core.js`

## Важно

Micn не заменяет финансового или юридического консультанта. Для серьёзных долгов обращайтесь к специалисту.
