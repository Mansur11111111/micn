# Micn

Финансовый помощник для людей, которым трудно с деньгами. Работает в браузере, данные хранятся только на вашем устройстве.

## Что умеет
- Учёт трат и способов оплаты, панель с диаграммой, цели с прогресс-баром
- Калькуляторы: накопления, долги (лавина и снежный ком), бюджет, бизнес (прибыль и безубыточность)
- План «Деньги кончились до зарплаты»
- Письма и заявления банку, арендодателю и другим организациям (шаблоны; с AI на сервере письма пишутся подробнее)
- Выгрузка трат в CSV

## Как запустить
- **Только сайт:** откройте `index.html` в браузере или включите GitHub Pages (Settings → Pages → Deploy from a branch → main / root).
- **Сайт с AI и Telegram-ботом:** нужен сервер (`index.js`, `package.json`) на Render или Replit. Ключи (`ANTHROPIC_API_KEY`, `TELEGRAM_BOT_TOKEN`) хранятся только в переменных окружения сервиса, в репозиторий их добавлять нельзя.

## Важно
Micn не заменяет финансового или юридического консультанта. Для серьёзных долгов обращайтесь к специалисту.
